Программа для разделения матрицы на блоки и распределения этих блоков между процессами с использованием MPI (mpi4py).

## Описание
Простенькая программка, которая:
- разбивает матрицу на блоки,
- отправляет блоки разным процессам через MPI,
- показывает, какой процесс получил какой блок.

Это удобная заготовка для дальнейшей параллельной обработки матриц.

## Требования
- Python 3.x  
- mpi4py  
- MPI (mpiexec / mpirun)

Установка зависимостей:
```bash
pip install mpi4py
```
## Запуск программы:

```bash
mpiexec -n 6 python program.py
