Программа для разделения матрицы на блоки и распределения этих блоков между процессами с использованием MPI (mpi4py).

## Описание
Простенькая учебная программка, которая:
- разбивает матрицу на блоки,
- отправляет блоки разным процессам через MPI,
- показывает, какой процесс получил какой блок.

Это удобная заготовка для дальнейшей параллельной обработки матриц.

## Требования
- Python 3.x  
- mpi4py  
- MPI (mpiexec / mpirun)

Установка зависимостей:
```bash
pip install mpi4py
```
## Запуск программы:
По умолчанию предполагается запуск на 6 процессах. Надо ввести в терминал:
```bash
mpiexec -n 6 python program.py
```
Чтобы запустить ее с другим числом процессом, необходимо заменить в "program.py" k1 и k2:
```text
k1, k2 = 2, 3
assert k1 * k2 == size, "numprocs != k1*k2"
```
Произведение k1 и k2 обязательно должно совпасть с числом процессов
